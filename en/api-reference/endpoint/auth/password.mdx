### Example Usage

<CodeGroup>
```bash cURL
curl -X POST "https://app.oryzacloud.app/auth/password" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json"
```

```javascript JavaScript (Fetch)
const response = await fetch("https://app.oryzacloud.app/auth/password", {
  method: "POST",
  headers: {
    "Accept": "application/json",
    "Content-Type": "application/json"
  }
});
const data = await response.json();
console.log(data);
```
