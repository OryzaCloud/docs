### Exemplo de Uso

<CodeGroup>
```bash cURL
curl -X GET "https://app.oryzacloud.app/api/client/account/api-keys" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer SUA_CHAVE_CLIENT_API"
```

```javascript JavaScript (Fetch)
const response = await fetch("https://app.oryzacloud.app/api/client/account/api-keys", {
  method: "GET",
  headers: {
    "Accept": "application/json",
    "Content-Type": "application/json",
    "Authorization": "Bearer SUA_CHAVE_CLIENT_API"
  }
});
const data = await response.json();
console.log(data);
```
